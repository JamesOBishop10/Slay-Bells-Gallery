Linear Gradient Background

The background has a linear-gradient background applied to the <body> element. The transition is from a darker shade [bottom] of blue to a lighter [top] shade of blue.

Header Navigation

The header navigation is created with the list of anchored <li> tags nested within the unordered <ul> list tags.

For example:

<ul>
<li>
<a href="index.html">Homepage</a>
</li>
<li>
<a href="page_2.html">Slay The Bells 1</a>
</li>
<li>
<a href="page_3.html">Slay The Bells 2</a>
</li>
<li>
<a href="page_4.html">Slay The Bells 3</a>
</li>
<li>
<a href="page_5.html">Bishop and Krampus page 1</a>
</li>
<li>
<a href="page_6.html">Bishop and Krampus page 2</a>
</li>
</ul>

Each <li> tag contains a link, <a>, to the corresponding page.
<a href="https://example.com”> </a>

About the Footer

The footer has a simple design with a copyright, creator name, and border. The intended behavior is for the footer to appear below all page content. However, due to a layout or positioning issue, the footer overlaps the content area when the page
is rendered, as illustrated in the screenshots below. This prevents the page elements from maintaining proper spacing and visual separation.
